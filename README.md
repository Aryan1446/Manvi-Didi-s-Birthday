# Happy Birthday, Manvi Didi

To personalise: drop your song at `frontend/public/assets/song.mp3` and photos in `frontend/public/assets/photos/` (plus `surprise.jpg`), then edit **`frontend/src/config.js`** — song path/title, photos array (src + caption, any length), surprise image/caption, note, your name, candle count and every text string live there (look for `REPLACE ME`).
